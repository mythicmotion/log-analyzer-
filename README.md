# log-analyzer-
A simple Python tool to parse and analyze web server access logs.  
It extracts key details like IP address, timestamp, request method, status code, and response size.  
Perfect for learning regex, log parsing, and basic security research.

---

## 🚀 Features
- Regex-based parsing of Apache/Nginx style logs
- Displays IP, request, status code, and size
- Error handling for missing files or invalid formats
- Easy to extend for custom log formats
